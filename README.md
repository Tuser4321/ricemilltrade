# Rice Mill Trade - Official B2B Website

Production-ready, highly accessible B2B website built with HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Cloudflare Pages Deployment Steps

1. Push code to your GitHub repository `ricemilltrade`.

2. Connect repository to Cloudflare Pages Dashboard.

3. Framework Preset: None (Static)

4. Build Output Directory: `/`

5. Click **Save and Deploy**.
